# CLAUDE.md — Thumbnail Generator

Command reference. For the model, the invariants and the traps, read
[AGENTS.md](AGENTS.md) first.

## Commands

```bash
npm install
npm run dev          # vite dev server (fleet launch.json: port 5210)
npm test             # vitest — 71 tests, no browser needed
npm run test:watch
npm run build        # tsc -b && vite build -> dist/
npm run preview      # serve the built dist/ (does NOT apply _headers)
npm run serve:dist   # serve dist/ WITH _headers applied — use this to check the CSP
npm run typecheck    # tsc -b
```

## Deploy

```bash
cf-run npx wrangler deploy
```

Or connect the repo in Cloudflare: build `npm ci && npm run build`, deploy
`npx wrangler deploy`. A static-assets **Worker**, not a Pages project.

## Ground rules

- Layout maths stays in `render/layout.ts` and stays pure. Painters fit content
  into the boxes it returns; they never decide where a box goes.
- The preview renders at the card's full raster through `renderCardTo` — never
  its own painter, never a convenient screen size.
- `resolve.ts` is the only place a null size or colour becomes a real one.
- Gradient stops are computed from the base colour. Never tabulate them.
- New icons go in `icons.ts` as `Shape[]` inside the 24×24 box. Don't vendor an
  icon set.
- A new image format is an entry in `ENCODERS` plus one line in `FormatId`.
- `ATTRIBUTIONS.md` and the About dialog are generated by `stoatworks-backend`.
  Don't hand-write them here.
